## Legenda de Prioridade

| Label | Descrição |
|---|---|
| `prio: high` | Essencial para o MVP — deve estar na próxima sprint |
| `prio: medium` | Importante, mas pode aguardar 1–2 sprints |
| `prio: low` | Desejável, entra quando houver capacidade |
