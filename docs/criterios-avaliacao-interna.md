# Critérios de Avaliação Interna — VaiJunto

> Documento de uso interno da equipe para autoavaliação das entregas antes de cada sprint.

---

## Checklist por Sprint

Antes de submeter cada sprint, verificar:

### Organização Geral
- [ ] O arquivo `docs/sprints/sprint-0X.md` está completo com todos os 11 itens do template
- [ ] O `docs/backlog-produto.md` está atualizado
- [ ] O repositório tem commit de cada integrante no período da sprint
- [ ] A tag `sprint-0X` foi criada no Git

### Qualidade do Conteúdo
- [ ] Os artefatos produzidos estão linkados no arquivo da sprint
- [ ] A relação com o conteúdo da disciplina está preenchida e coerente
- [ ] O Kanban reflete o estado real das tarefas
- [ ] As dificuldades e pendências estão documentadas honestamente

### GitHub
- [ ] Issues abertas para os itens do backlog
- [ ] Labels de prioridade aplicadas
- [ ] Milestone da sprint configurado
- [ ] README.md atualizado se houver mudanças estruturais

### Aplicação Web
- [ ] Nenhuma funcionalidade foi removida sem justificativa
- [ ] O código segue princípios de Clean Code (nomes expressivos, funções coesas)
- [ ] Nenhuma credencial ou dado sensível foi commitado
